# Docs

Project documentation lives directly in this folder, one file per topic, named for what it covers
(`architecture.md`, `deploy.md`, `auth-flow.md`). Add a subfolder only when one topic grows past a
single file.

- [bugs.md](bugs.md) — at-a-glance defect index. GitHub Issues is the source of truth.

Agent-facing rules live in `../AGENTS.md`.
